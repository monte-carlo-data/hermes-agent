{{/*
  Deliberately free of `lookup`: reading cluster state would make this render
  differently under `helm template`, `--dry-run`, and the Terraform helm
  provider's plan phase, and would require `get secrets` on the caller. Naming
  what the release expects is enough. See `hermes.oauth.enabled` and
  `hermes.auth.source` in _helpers.tpl for how the method and source are
  selected.
*/}}
{{- $ns := .Values.namespace | default "mcd-agent" -}}
{{- $oauth := eq (include "hermes.auth.method" .) "oauth" -}}
{{- $source := include "hermes.auth.source" . -}}
{{- $secretName := ternary "mcd-oauth-secret" "mcd-agent-token-secret" $oauth -}}
{{- $secretKey := ternary "credentials.json" "contents.json" $oauth -}}
{{- $payload := ternary "{\"client_id\": \"...\", \"client_secret\": \"...\"}" "{\"mcd_id\": \"...\", \"mcd_token\": \"...\"}" $oauth -}}
Monte Carlo Generic Agent deployed to namespace {{ $ns }}.

This release authenticates with {{ if $oauth }}OAuth client credentials{{ else }}a key/token pair{{ end }} and reads them from:
{{ if eq $source "awsSecretsManager" }}
  AWS Secrets Manager: {{ (ternary .Values.oauthSecret .Values.tokenSecret $oauth).awsSecretsManager.secretId }}
  Payload:             {{ $payload }}

The agent reads this secret itself — no Kubernetes Secret is created. Its
service account must be able to call secretsmanager:GetSecretValue on that
secret; without it the agent starts and then fails to authenticate.
{{- else }}
  Secret:  {{ $secretName }} (key: {{ $secretKey }})
  Payload: {{ $payload }}
  Source:  {{ if eq $source "externalSecret" }}synced by the External Secrets Operator{{ else }}created manually with kubectl{{ end }}

The agent pod stays in ContainerCreating until that Secret exists. It does not
have to exist before install — the kubelet retries the mount and the pod starts
on its own once the Secret appears.
{{- end }}

If that is not the credential you configured, the release selected the other
authentication method. To switch:
{{ if $oauth }}
  remove the `oauthSecret` block to use key/token authentication
{{- else }}
  set `oauthSecret.enabled: true` with a credential source{{ if eq $source "k8sSecret" }} — none needed,
  you create mcd-oauth-secret yourself{{ else }}, `oauthSecret.{{ ternary "awsSecretsManager.secretId" "remoteRef" (eq $source "awsSecretsManager") }}`{{ end }},
  then remove `tokenSecret`
{{- end }}

Verify connectivity to Monte Carlo:

  kubectl exec -n {{ $ns }} deploy/mcd-agent-deployment -- \
    curl -s -X POST localhost:8080/api/v1/test/reachability

A successful response contains "ok": true. On failure the response reports the
credential the agent is configured with and the source it was read from, which
tells you whether the intended credential was picked up.
